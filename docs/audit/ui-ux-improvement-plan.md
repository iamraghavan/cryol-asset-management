# Console and registry interaction plan

Use inventory identifiers and find-by-tag workflows from Snipe-IT, filter-to-work-list navigation from enterprise hardware workspaces, and compact entity-oriented navigation from CRM consoles. Cryol uses its own colors, typography and layouts. [Snipe-IT managing assets](https://snipe-it.readme.io/v8.6.0/docs/managing-assets) · [ServiceNow hardware asset overview](https://www.servicenow.com/docs/r/it-asset-management/hardware-asset-management/hardware-asset-overview.html) · [Zoho CRM](https://www.zoho.com/crm/)

Use an accessible modal primitive for off-canvas record work. Keep search, filters and current page in the registry URL while drawers are open. Use server authorization for searches and every record action. Start with asset search, since assets are the operational entity with persisted data and permissions today. [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog) · [shadcn Sheet](https://ui.shadcn.com/docs/components/sheet)

Sequence the work through console and search, reusable drawer, real registry operations, then directory and custody, followed by reporting and browser regression. Add controls alongside the server behavior they represent.

Zoho Creator's registration model separates identification from purchase and lifecycle information. Asset Panda connects asset details to activity and history. Freshservice illustrates the value of a discovery feed that updates inventory, and AssetExplorer distinguishes software observations from license entitlements. Snipe-IT's custody workflows inform a later assignment phase. [Zoho Creator](https://www.zoho.com/creator/solutions/asset-management/) · [Asset Panda](https://www.assetpanda.com/) · [Freshservice](https://www.freshworks.com/freshservice/) · [ManageEngine AssetExplorer](https://www.manageengine.com/products/asset-explorer/) · [Snipe-IT](https://snipe-it.readme.io/docs/overview)

The current code uses Radix Dialog directly for primitives and shared CSS for tokens and layouts. TanStack Query handles cancellation, caching and invalidation. TanStack Table manages columns and selection. React Hook Form and Zod handle form state and client validation. React Router puts list controls and record selection in the URL and blocks navigation from a dirty drawer. Lucide provides consistent icons. [TanStack Query](https://tanstack.com/query/latest) · [TanStack Table](https://tanstack.com/table/latest) · [React Hook Form](https://react-hook-form.com/) · [Zod](https://zod.dev/) · [React Router](https://reactrouter.com/) · [Lucide](https://lucide.dev/)
